# Studli – UI/UX Design

Studli is a student productivity app concept designed in Figma to make studying easier and more organized.

### Screens
- Home
- Planner
- Progress
- Profile
- Study Partner

### Design Highlights
- Lavender-themed interface
- Interactive prototype
- Alternative layouts for Home and Planner
